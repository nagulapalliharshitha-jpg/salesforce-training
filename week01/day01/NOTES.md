1.What problem does Salesforce solve?
        Salesforce solves the problem of managing customer relationships and business operations efficiently.
Many companies face difficulties in storing customer data and tracking sales activities.
Salesforce provides a cloud-based CRM platform to manage all customer information in one place.
It helps businesses improve communication, automate tasks, and provide better customer service.
This increases productivity and helps companies grow their business effectively.

2.What is CRM?
         CRM stands for **Customer Relationship Management**.
It is a system used to manage customer information and business interactions.
CRM helps companies track sales, customer details, and communication in one place.
It improves customer service and helps businesses build better relationships with customers.
Salesforce is one of the most popular CRM platforms used by companies worldwide.

3.What is an Object in Salesforce? Give one example.
          In Salesforce, an Object is a database table used to store specific types of information.
Objects contain records and fields to organize data efficiently.
Each object stores related information in a structured format.
For example, a "Student Object" can store student details like name, roll number, and department.
Standard Salesforce objects include Lead, Account, and Contact.

4.Difference between Salesforce Admin and Developer.
         A Salesforce Admin manages and configures the Salesforce platform using built-in tools and features. They handle users, reports, workflows, and system settings without much coding.
         A Salesforce Developer builds custom applications and advanced functionalities on the Salesforce platform. They use programming languages like Apex and technologies like Lightning Components to create custom business solutions.
         In simple words, an Admin mainly works with configuration and management, while a Developer focuses on coding and application development.

5.Suggest one real-world application that can be built using Salesforce.
          A **College Management System** can be built using Salesforce.
          It can be used to manage student records, attendance, courses, faculty details, and fee information.
          The system helps colleges store all data in one centralized platform.
          It also improves communication between students, teachers, and administration.
          This makes college management more efficient and organized.
